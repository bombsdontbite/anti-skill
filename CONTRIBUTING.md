# Contributing

**A bug:** open an issue with the **Install problem** or **Bug report** form. Remove paths, keys and
anything private from what you paste. A security problem goes privately: see [SECURITY.md](SECURITY.md).

**A small fix** (a typo, a broken link, a script bug): open a pull request. For anything bigger,
open an issue first that says what and why.

**A new skill, or a change to a skill,** is accepted only with a measurement: plain Claude Code and
Claude Code with the skill, on the same task with the same instructions and limits, scored on data
neither was tuned on. Include the runs, wins and losses alike. See
[how the numbers were measured](eval/README.md).

Contributions are released under the [MIT license](LICENSE).
