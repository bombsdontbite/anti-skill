# Benchmarks and runs

Each folder is one benchmark, with its scorers, its tasks and the runs scored on it.

| Folder | What it measures |
|---|---|
| [`loop-bench/`](loop-bench/README.md) | Optimisation tasks with automatic scorers: evolve against plain Claude Code |
| [`profile-first-bench/`](profile-first-bench/README.md) | Where a program's time goes, and how much each part takes |
| [`arms/`](arms/README.md) | The shared harness that runs a draft skill against plain Claude Code |
| [`RUNS-ARCHIVE.md`](RUNS-ARCHIVE.md) | The agents' working files from every run, in an archive on the release |
